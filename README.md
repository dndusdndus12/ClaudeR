# Clauder

중국어 웹소설을 Claude로 번역해서 읽는 개인용 안드로이드 앱입니다.
앱 안의 브라우저로 소설 사이트를 열고, 버튼 하나로 현재 회차를 번역해 전자책 리더처럼 읽습니다.

> **Inspired by ['소설번역기' 앱](https://play.google.com/store/apps/details?id=com.kirschx.fdbstranslator2&hl=ko).**
> 그 앱에서 아쉬웠던 기능을 채우려고, Claude 전용으로 직접 만들었습니다.
> 이 프로젝트는 해당 앱과 관련이 없는 별개의 개인 프로젝트이며, 그 앱의 코드나 자산을 사용하지 않았습니다.

## 주요 기능

**브라우저와 본문 추출**

- 앱 안의 WebView 브라우저로 소설 사이트를 일반 브라우저처럼 엽니다. 쿠키를 유지하고 JavaScript를 켭니다.
- 앱이 페이지를 직접 받아오지 않고, 항상 브라우저가 로드한 페이지에서 본문을 추출합니다.
- 글이 가장 많이 모인 블록을 자동으로 찾아 메뉴, 광고, 홍보 문구, 저작권 문구, 작가 후기를 걸러 냅니다.
- 자동 추출이 안 맞는 사이트는 도메인별 CSS 선택자 규칙(본문, 제목, 다음 화 링크)을 지정할 수 있습니다.
- 다음 화와 이전 화 링크를 자동으로 인식합니다(`rel="next"`, 下一章, 下一页, Next, 다음 등).

**번역**

- Anthropic Messages API의 스트리밍으로 번역문을 받는 대로 표시합니다.
- 모델은 API의 모델 목록에서 불러와 고릅니다.
- 긴 회차는 문단 경계에서 나눠 순서대로 번역합니다.
- 프롬프트 캐싱을 적용합니다. 매번 같은 프롬프트 부분은 캐시하고, 회차마다 달라지는 용어집은 그 뒤에 둡니다.
- 모델이 거절하거나 일부만 출력하면 한 번 자동으로 다시 시도합니다.
- API 키를 여러 개 등록하면 인증 실패, 요청 한도, 크레딧 소진, 과부하 때 다음 키로 넘어갑니다.
- 설정에서 켜면 회차를 읽는 동안 다음 1회차를 미리 번역해 둡니다(기본은 꺼짐).

**프롬프트와 용어집**

- 전역 설정과 작품별 설정을 따로 둘 수 있습니다.
- 용어집은 한 줄에 하나씩 `原文=번역` 형식으로 붙여넣습니다. 형식이 틀린 줄과 중복 수를 알려 줍니다.
- 전역 용어집과 작품 용어집을 합치되 작품 쪽이 우선하고, 그 회차 원문에 실제로 나오는 항목만 보냅니다.

**뷰어와 서재**

- 글자 크기, 줄 간격, 여백, 테마(밝게, 어둡게, 세피아)를 조절합니다.
- 화면을 탭하면 위아래 막대가 숨겨집니다.
- 볼륨 키로 한 화면씩 넘깁니다. 키 대신 "밀기" 터치를 보내는 블루투스 리모컨도 지원합니다.
- 페이지 넘김 전용 모드에서는 스크롤 없이 한 장씩 넘기고, 줄이 화면 끝에서 잘리지 않습니다.
- 번역한 회차는 기기에 저장해서 다시 열 때 API를 부르지 않습니다.
- 작품별로 마지막으로 본 회차와 읽던 위치를 기억해 이어서 볼 수 있습니다.

**사용량과 설정 관리**

- 회차별 토큰 수와 월별 토큰 합계를 보여 줍니다. API가 응답으로 알려 준 값만 적습니다.
- 금액은 계산하지 않습니다. 실제 요금과 남은 크레딧은 Claude Console에서 확인합니다(일반 API 키로는 조회할 수 없습니다).
- 프롬프트, 용어집, 사이트 규칙, 뷰어 설정을 JSON 파일로 내보내고 가져올 수 있습니다. API 키는 내보내지 않습니다.

## 사용 방법

1. 설정 > AI 설정에서 Anthropic API 키를 등록하고 모델을 고릅니다.
2. 번역 탭에서 소설 사이트의 회차 페이지를 엽니다.
3. 아래의 **번역** 버튼을 누릅니다.
4. 뷰어에서 **다음 화**를 누르면 다음 회차로 이동해 번역까지 이어서 진행합니다.

API 키는 Android Keystore로 암호화해 기기 안에만 저장합니다. 번역 요청은 기기에서 Anthropic API로 직접 보내며, 그 요금은 등록한 키의 계정에 청구됩니다.

## 빌드

Android Studio 없이 명령줄만으로 빌드할 수 있습니다.

필요한 것:

- JDK 17 이상
- Android SDK (platform 37.1, build-tools 36.0.0, platform-tools)
- 환경 변수 `ANDROID_HOME` 또는 프로젝트 루트의 `local.properties`에 `sdk.dir` 지정

```
./gradlew assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 만들어집니다. USB 디버깅을 켠 기기에 설치하려면:

```
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

단위 테스트:

```
./gradlew testDebugUnitTest
```

본문 추출 스크립트(`app/src/main/assets/extractor.js`)는 브라우저에서 따로 시험할 수 있습니다.
프로젝트 루트에서 `python -m http.server 8765`를 실행하고 `http://localhost:8765/tools/extractor-test/`를 엽니다.

## 기술 구성

| 영역 | 사용한 것 |
|---|---|
| 언어, UI | Kotlin, Jetpack Compose |
| 저장 | Room(작품, 회차), DataStore(설정) |
| API 키 보관 | Android Keystore 기반 AES-GCM 암호화 |
| 네트워크 | OkHttp, SSE 스트리밍 직접 처리 |
| 대상 | minSdk 26, targetSdk 37 |

코드 구조:

```
app/src/main/java/com/clauder/reader/
  ai/         공급자 인터페이스, Claude 구현, 스트리밍 해석, 키 순환
  browser/    WebView 브라우저와 본문 추출 호출
  extract/    추출 결과 정리(홍보 문구, 작가 후기 제거)
  translate/  번역 흐름, 프롬프트 구성, 용어집, 회차 분할
  data/       설정, API 키, 작품과 회차 저장소
  ui/         뷰어, 서재, 설정 화면
app/src/main/assets/
  extractor.js        페이지에서 본문과 이전/다음 링크를 뽑는 스크립트
  default_prompt.txt  기본 번역 프롬프트
```

번역 공급자는 인터페이스(`AiProvider`)로 분리되어 있습니다. 지금은 Claude만 구현되어 있고, Gemini는 설정 화면에 자리만 있습니다.

## 알아둘 점

- 개인이 자기 기기에서 쓰려고 만든 앱입니다. 스토어에 배포하지 않습니다.
- 광고 차단, 원문 대조 기능은 없습니다.
- 미리 번역을 켜면 읽지 않은 회차에도 요금이 나갑니다.
- 이용하는 사이트의 약관과 작품의 저작권은 사용자가 지켜야 합니다. 번역 결과물은 개인적으로 읽는 용도로만 쓰세요.
- 보안 확인(봇 검사) 페이지는 앱이 우회하지 않습니다. 브라우저 화면에서 직접 통과해야 합니다.

## 만든 과정

[Claude Code](https://claude.com/claude-code)와 함께 단계별(M0~M5, 그 뒤 미리 번역 추가)로 개발했습니다. 커밋 기록에 각 단계가 남아 있습니다.
